# Data Model: Backend Core & Data Layer

## Task Entity

### Fields
- **id** (Integer, Primary Key, Auto-increment)
  - Unique identifier for each task
  - Auto-generated by the database
- **title** (String, Required)
  - The main content/description of the task
  - Maximum length: 255 characters
- **description** (String, Optional)
  - Detailed information about the task
  - Maximum length: 1000 characters
  - Can be null
- **completed** (Boolean)
  - Indicates whether the task is completed
  - Default value: False
- **user_id** (String/Integer, Required, Foreign Key reference)
  - Links the task to a specific user
  - Used for enforcing data isolation
  - Required for all queries to filter results
- **created_at** (DateTime)
  - Timestamp when the task was created
  - Auto-populated on creation
- **updated_at** (DateTime)
  - Timestamp when the task was last modified
  - Auto-updated on modifications

### Relationships
- **User**: Each task belongs to one user (many-to-one relationship)
  - Tasks are filtered by user_id for data isolation
  - When a user is removed, their tasks should also be removed (to be handled in future specs)

### Validation Rules
- **title**: Required field, minimum 1 character, maximum 255 characters
- **description**: Optional field, maximum 1000 characters if provided
- **completed**: Boolean value, defaults to False
- **user_id**: Required field, must match an existing user (in future specs with user management)

### State Transitions
- **Creation**: New task is created with completed=False
- **Update**: Task details can be modified (title, description)
- **Completion Toggle**: completed field can be toggled between True/False
- **Deletion**: Task is removed from the database

## API Data Contracts

### Task Creation (POST /api/{user_id}/tasks)
**Request Body**:
```json
{
  "title": "string (required, 1-255 chars)",
  "description": "string (optional, 0-1000 chars)",
  "completed": "boolean (optional, defaults to false)"
}
```

**Response (201)**:
```json
{
  "id": "integer",
  "title": "string",
  "description": "string or null",
  "completed": "boolean",
  "user_id": "string/integer",
  "created_at": "datetime string",
  "updated_at": "datetime string"
```
